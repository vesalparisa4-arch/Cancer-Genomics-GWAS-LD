# Cancer Genomics: Genetic Association and Linkage Disequilibrium
Computational Biomedicine, Tutorial 2. Educational case-control example from chromosome 10 (not a genome-wide clinical discovery). Genotype QC, single-SNP association, multiple-testing correction, Manhattan plots and population LD comparison using R/snpStats. 1,000 participants and 28,501 SNPs before QC.

## Run
Use the authorized course input `data/snps_10.dat`, then run `Rscript analysis.R` from this folder. Original figures in `figures/` were independently computed in Python as numerical pre-checks. They are not R output. The R code was not executed in the original preparation environment; verify locally. Check course and data permission before publication.
